Arquitetura técnica

Simples de hospedar, mas com acabamento de aplicação.

A proposta técnica é reduzir dependências: o site abre por GitHub Pages, funciona no celular e mantém uma demonstração local controlada.

Fluxo do sistema

1
GitHub Pages

Entrega os arquivos HTML, CSS, JS e imagens como site estático gratuito.

2
Navegador do usuário

Executa filtros, quiz, modal, formulários e armazenamento local sem servidor.

3
localStorage v2

Guarda posts e mural da demonstração no dispositivo atual, com exportação/importação em JSON.

4
Service Worker

Cria cache básico para o site abrir novamente mesmo com conexão instável.

Critérios técnicos

PWAManifest, tema, ícone e cache offline básico.
SEOMetadados, Open Graph e estrutura semântica.
A11yLabels, foco visível, modal acessível e teclado.
MobileLayout sem sobreposição e botões com área de toque confortável.

Limite atual: GitHub Pages sozinho não sincroniza dados entre pessoas. Para isso, a próxima versão precisaria de backend, banco ou serviço externo.
